# docs/snapshots/

Point-in-time reviews — dated assessments of product quality, test sessions, due-diligence
audits, roadmap observations. Filenames are dated: `YYYY-MM-DD_topic.md`
(e.g. `2026-06-10_due_diligence_audit.md`).

**Conventions**

- **A snapshot is frozen.** It captures what was true on its date; you don't update an old
  snapshot, you write a new one. This is what makes it useful as a historical record.
- **Snapshots feed the backlog.** Findings that need action get promoted into the
  "Discovered / unscheduled" section of `docs/plan.md` (or a `docs/projects/` file) — the
  snapshot itself stays as the evidence.
- Like logs, snapshots are **not** in the Projects Index.

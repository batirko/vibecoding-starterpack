# Example observation log

> **Template example.** Append-only. Newest entries at the top. Delete this file once you
> have a real log; it is not tracked by the Projects Index.

## 2026-07-07

- **Observation.** One line on what you saw — a false positive, a rough edge, a surprising
  behaviour. Enough context that a future reader (or agent) can act on it without you.
- **Context.** Where it happened (which flow, which input). Don't fix it here — just record it.
